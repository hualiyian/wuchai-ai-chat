## 🛠️ 配置指南

### 使用本地 Ollama 模型

1. 从 [ollama.com](https://ollama.com) 下载并安装 Ollama
2. 在终端拉取模型：
   ```bash
   ollama pull llama3
   ```
3. 打开吾侪AI对话框 → 设置 → 添加 Ollama 模型（默认地址 `http://localhost:11434`）

### 配置云端 API
支持的主流平台（均需自行注册并获取 API Key）：

| 平台 | 默认模型 | 注册地址 |
|------|---------|----------|
| 🧠 DeepSeek | deepseek-chat | deepseek.com |
| 🔵 OpenAI | gpt-3.5-turbo / gpt-4 | platform.openai.com |
| 🟢 通义千问 | qwen-plus | dashscope.console.aliyun.com |
| 🟣 智谱 AI | glm-4-flash | open.bigmodel.cn |
| 🟡 Kimi | moonshot-v1-8k | platform.moonshot.cn |
| ⚡ Groq | llama-3.3-70b-versatile | console.groq.com |

操作步骤：
1. 选择平台 → 注册账号 → 生成 API Key
2. 吾侪AI对话框 → 设置 → 添加云端模型 → 选对应平台 → 粘贴 Key → 保存

### 购买吾侪网关 Token
1. 打开微信 → 搜索小程序「**慢的你**」
2. 选择 Token 按量套餐（随用随买，无使用期限）
3. 支付完成后获取 API Key
4. 粘贴到应用设置 → 吾侪网关 栏即可

## 🚀 快速上手

### 💬 智能对话
点击左侧「对话」，选择模型后直接输入问题即可。支持：
- 多轮上下文记忆，追问无需重复背景
- Markdown 渲染，代码块/表格/公式完美显示
- 一键复制回复、继续追问、重新生成

### 🧠 知识库问答（入门版+）
1. 左侧进入「知识库」→ 新建知识库
2. 上传 **TXT / Markdown** 等文档
3. 等待向量化完成（通常几秒）
4. 回到对话界面，选择对应知识库后提问，模型会只基于你的文档回答

> 💡 **典型场景**：上传公司制度、产品手册、技术文档，让 AI 成为你的专属顾问

### 🌐 网页端口（旗舰版）
1. 设置 → 网页端口 → 开启服务
2. 手机/平板/其他设备浏览器访问 `http://<你的电脑IP>:8080`
3. 局域网内任何设备都能使用同一套 AI 对话 + 知识库

> 💡 适合家里多设备、或办公室同事共享使用

### 🌐 翻译
左侧进入「翻译」，支持：
- 中英日韩法德等主流语言互译
- 段落级实时翻译，输入即出结果

### 🔍 联网搜索
对话时切换到「联网搜索」模式，AI 会：
- 实时抓取互联网最新信息
- 自动去重、整合多源结果
- 标注引用来源，方便溯源

## ❓ 常见问题

**Q: 为什么安装后提示缺少 DLL？**
A: 请确保安装了 [Visual C++ 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)（Windows 10/11 一般已自带）。

**Q: 本地模型响应慢？**
A: 小模型（如 `llama3:8b`）速度快，大模型（如 `llama3:70b`）需要更强的 GPU。入门推荐 8B 级模型。

**Q: 激活码如何兑换？**
A: 打开应用 → 右上角会员中心 → 兑换激活码。

**Q: 会员授权和吾侪网关是什么关系？**
A: 两者独立计费：会员按年授权解锁应用内置功能（知识库、Ollama、网页端口等）；吾侪网关是额外的云端 API 服务，按 Token 消耗量计费。免费版也可单独购买网关 Token 使用。
